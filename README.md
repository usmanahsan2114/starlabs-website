# Star Laboratories (Pvt) Ltd — Corporate Website

Official corporate website and pharmaceutical product catalog for **Star Laboratories (Pvt) Ltd**, a leading WHO-GMP certified and DRAP licensed pharmaceutical manufacturer based in Lahore, Pakistan (established 1960).

## Overview
- **Production URL:** [https://starlabs.com.pk](https://starlabs.com.pk)
- **Headquarters:** 23, K.M. Multan Road, Lahore 53800, Pakistan
- **Regulatory Accreditations:** WHO-GMP, DRAP Manufacturing License, ISO 9001:2015, ISO 14001:2015, ISO 45001:2018
- **Export Recognition:** PPMA PESA Top Exporter Award (2023 & 2024)
- **Portfolio:** 482 formulations across Human & Veterinary medicine (injectables, oral solids, oral liquids, suspensions, topical, aerosols, drenches, and powders)

## Architecture & Features
- **Core Engine:** PHP (native responsive templates, centralized SEO engine in `include/seo.php`)
- **UI / Styling:** Responsive Vanilla CSS architecture (`css/style.css`, `css/responsive.css`, `css/sl-enhancements.css`)
- **Structured Data:** Full Schema.org graph (`Organization`, `MedicalBusiness`, `Drug`, `Product`, `Person`, `BreadcrumbList`)
- **Search Architecture:** Segmented XML sitemaps index (`sitemap.xml`, `sitemap-main.xml`, `sitemap-products-veterinary.xml`, `sitemap-products-human.xml`, `sitemap-manufacturing.xml`, `sitemap-news.xml`)
- **AEO / LLM Readiness:** Machine-readable context endpoints (`/llms.txt`, `/llms-full.txt`)
