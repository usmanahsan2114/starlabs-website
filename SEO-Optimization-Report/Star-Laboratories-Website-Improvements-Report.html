Foundation

Technical SEO & AEO

"AEO" = Answer Engine Optimisation — making the site readable to AI answer engines such as Google AI Overviews, ChatGPT and Perplexity, alongside traditional SEO.

Before
  • Every page declared lang="zxx" — tells Google "no language"
  • Identical <title>Star Labs Website</title> on 499 pages
  • Empty meta descriptions site-wide
  • No canonical URLs, no structured data, no robots.txt
  • Sitemap covered only 108 of 528 pages
After
  • Correct lang="en" + hreflang for Pakistan & global
  • Unique, keyword-rich titles & descriptions on every page
  • Full JSON-LD structured data on all pages
  • Canonical URLs, Open Graph & Twitter cards everywhere
  • Complete 499-URL sitemap + robots.txt + AI-crawler rules

⚙ Centralised SEO engine

  • One file — include/seo.php — powers correct metadata for all 500 page templates
  • Auto-detects each page; new products inherit best-practice SEO automatically
  • Curated copy for 15 key pages, auto-generated for 483 product pages

{ } Structured data (JSON-LD)

  • Organization + LocalBusiness — pharmaceutical manufacturer entity
  • Product + Drug schema on 483 product pages
  • BreadcrumbList, WebSite search, FAQPage for rich results

🤖 AI / Answer-engine readiness

  • llms.txt & llms-full.txt — machine-readable company & catalogue map
  • robots.txt explicitly welcomes GPTBot, ClaudeBot, PerplexityBot & others
  • Clean entity data so AI answers cite Star Laboratories accurately

🗂 Crawl & index files

  • Regenerated sitemap.xml — all 499 URLs, priorities, hreflang
  • New robots.txt, site.webmanifest, branded 404 page
  • 483-product structured database (products-data.php)
Speed & safety

Performance & Security

Faster loads improve both rankings and conversions; security headers protect the site and its visitors.

⚡ Performance

  • 1,104 images set to lazy-load with async decoding
  • Header logo flagged high-priority for faster first paint
  • Render-blocking scripts deferred; duplicate Font Awesome removed
  • Resource hints (preconnect, dns-prefetch) added

🛡 Security & caching (.htaccess)

  • GZIP / Brotli compression + 1-year static-asset caching
  • Security headers — X-Frame-Options, HSTS, Referrer-Policy, etc.
  • HTTPS + www canonicalisation (production-only, dev-safe)
  • Directory listing disabled; sensitive files blocked
Rebuilt from the ground up

Major Components Rebuilt

Several key components were broken or conflicting. Rather than patching, these were rebuilt cleanly with scoped, conflict-free code.

Rebuilt Products Page — search, sort & filter workflow

The sort dropdown did nothing, product cards rendered oversized from theme-CSS bleed, and the filters fought the pagination. Rebuilt as one unified browser with scoped styling.

  • Live product search by name
  • Working sort — Featured, A–Z, Z–A, Category
  • Category accordion + checkboxes that filter together with search
  • Pagination on the filtered set, active-filter chips, empty state
  • Reads ?q= from the URL (powers site search)
  • All 122 listed products preserved

Rebuilt Global Presence — interactive world map

The export map had become invisible and used fragile pixel-math. Rebuilt as a modern, robust section.

  • World map (3/4 width) with location markers for 30 export countries
  • Searchable country list (1/4 width) — click to highlight on the map
  • Animated stat counters — 30+ Countries, 3 Continents, 60+ Years
  • Fully responsive; markers reposition reliably on load & resize

New Product Enquiry Workflow (not e-commerce — quotation only)

Product pages had a single generic "Contact Us" link and the contact form didn't actually send. Replaced with a complete enquiry system.

  • Every product page: "Request a Quotation" + "Enquire on WhatsApp" buttons
  • WhatsApp opens a pre-filled message naming that exact product
  • Contact form auto-fills the product name, subject & a structured message
  • "Contact Us" tab rebuilt into a compact, product-aware enquiry form
  • New PHP mail handler (send-enquiry.php) — emails sales, with spam protection
  • Captures country — useful for export enquiries

Rebuilt Language Selector & Product Detail Tabs

The translator used a fragile show/hide hack; the product tabs were plain and letter-spaced.

  • Custom 13-language dropdown that reliably drives Google Translate
  • Remembers the chosen language; hides Google's intrusive banner
  • Works on mobile; accessible (ARIA, keyboard)
  • Composition / Pack Sizes / Contact Us tabs redesigned — modern pill tabs & cards
